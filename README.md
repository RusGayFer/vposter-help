# Документация Впостер

[Впостер](https://vposter.ru) – универсальный сервис с широким набором инструментов для эффективного управления социальными сетями. Этот многофункциональный веб-сервис обеспечивает огромный набор возможностей, помогая руководителям и специалистам в эффективной организации работы с социальными сетями.

{% hint style="success" %}
Сервис Впостер для своей работы использует только **официальные методы API** социальных сетей.
{% endhint %}

## Возможности сервиса

* отложенный постинг постов
* отложенный постинг историй
* автоматическая маркировка рекламы через ОРД VK
* авто-публикации
* Нейросеть
* Callback уведомления
* антиспам
* rss-парсер
* боты
* автопостинг
* аналитика
* конструктор динамических обложек
* поиск контента
* автоворонки
* граббер
* кросспостинг из VK
* конкурсы
* экспорт товаров
* мессенджер диалогов
* Впостер AdsMarket
* анонимные сообщения и анонимные комментарии

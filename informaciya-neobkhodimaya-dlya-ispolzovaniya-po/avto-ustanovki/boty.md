# Боты для ВКонтакте

На нашем сервисе Вы можете подключить различных готовых ботов в сообщество:

* VK Истории Бот
* AI Ассистент-бот
* Комментатор-бот
* Чат-бот
* Анонимный чат
* Wikipedia-бот
* Погода-бот
* Голосовой бот
* Факт-бот
* Мем-бот.

Данные боты устанавливаются в сообщения сообщества кроме "Комментатор-бота" (он работает в комментариях сообщества) и выполняют свои функции. Всех этих ботов Вы можете изучить внутри сервиса при подключении.

## VK Истории Бот

С помощью этого бота вы сможете настроить автоматический репост всех ваших публикаций в истории ВКонтакте. Этот бот позволяет автоматически делиться вашими постами в истории, повышая их видимость и взаимодействие с ними. Теперь вам не придется вручную дублировать контент в истории — бот сделает это за вас, экономя ваше время и усилия.

## AI Ассистент-бот

Модуль позволяет устанавливать [AI Ассистента](neiroset/) прямо в сообщения вашего сообщества ВКонтакте.

## Комментатор-бот

Модуль позволяет устанавливать автоматические ответы на комментарии по ключевым словам. Бот будет отвечать за Вас в комментариях под постами.

## Чат-бот

С помощью этого модуля вы сможете назначить команды боту. Бот за Вас будет отвечать на сообщения пользователей Вашими указанными ответами. Можете настроить различные ответы и на каждый ответ разные кнопки.

## Анонимный чат

Анонимный чат добавляет возможность пользователям общаться анонимно через сообщения группы. Пользователи могут сами выбирать пол своего собеседника. Для скрытия клавиатуры используйте команду !**кнопкистоп**. Чтобы запустить чат отправьте **Начать**.

## Wikipedia-бот

Модуль добавляет команду **/wiki Слово для поиска**. В ответ на сообщение с командой пользователю будет отправлена информация об этом слове. Можно совмещать с другими ботами.

## Погода-бот

Модуль добавляет команду **/weather Город**. В ответ на сообщение с командой пользователю будет отправлена погода. Можно совмещать с другими ботами.

## Голосовой бот

Модуль добавляет голосового бота в сообщество. Бот преобразует текстовые сообщении в голосовые.

## Факт-бот

Модуль добавляет команду **/fact** при вводе которой пользователь получит случайный факт. Можно совмещать с другими ботами.

## Мем-бот

Модуль добавляет команду **Хочу мем** при вводе которой пользователь получит случайный мем. Можно совмещать с другими ботами.

## Подключение

Чтобы подключить бота в сообщество перейдите в раздел [Боты](https://vposter.ru/bots).&#x20;

Выберите сообщество и тип бота (нажимая справа на кружок).

Далее нажмите на кнопку **Добавить сообщество**.

![](<../../.gitbook/assets/Безымянный (28).png>)

В правом блоке «Активные сообщества« появится Ваше сообщество.

После по порядку нажмите **Получить ключ сообщества** и **Установить сервер**.

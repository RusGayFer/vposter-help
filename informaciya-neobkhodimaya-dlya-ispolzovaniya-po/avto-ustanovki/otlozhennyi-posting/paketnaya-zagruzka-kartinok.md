# Пакетная загрузка картинок

## Что такое пакетная загрузка картинок?

Пакетная загрузка картинок - это массовая загрузка изображений для постов. Сколько картинок загрузите, столько и запланируете постов. На каждую картинку будет создан отдельный пост.

## Как воспользоваться пакетной загрузкой?

Откройте раздел "Отложенные посты" и выберите подраздел "Пакетная загрузка картинок".&#x20;

<figure><img src="../../../.gitbook/assets/Снимок экрана 2024-04-01 030207.png" alt=""><figcaption><p>Выбор раздела</p></figcaption></figure>

В данном разделе вам нужно будет выбрать сообщество, в которое хотите загрузить картинки и выбрать сами картинки.

<figure><img src="../../../.gitbook/assets/Снимок экрана 2024-04-01 030442.png" alt=""><figcaption><p>Форма пакетной загрузки картинок</p></figcaption></figure>

{% hint style="warning" %}
Для выбора сразу нескольких изображений с компьютера удерживайте клавишу Ctrl.&#x20;
{% endhint %}

# Пакетная загрузка видео

## Что такое пакетная загрузка видео?

Пакетная загрузка видео - это массовая загрузка видео для постов. Сколько видеозаписей загрузите, столько и запланируете постов. На каждую видеозапись будет создан отдельный пост.

## Как воспользоваться пакетной загрузкой?

Откройте раздел "Отложенные посты" и выберите подраздел "Пакетная загрузка видео".&#x20;

<figure><img src="../../../.gitbook/assets/image (30).png" alt=""><figcaption><p>Выбор раздела</p></figcaption></figure>

В данном разделе вам нужно будет выбрать сообщество, в которое хотите загрузить видео и выбрать сами видеозаписи.

<figure><img src="../../../.gitbook/assets/image (31).png" alt=""><figcaption><p>Форма пакетной загрузки видео</p></figcaption></figure>

## Ограничения для видео

* **ВКонтакте**: максимальный размер видеозаписи — 100 МБ.
* **Одноклассники**: максимальный размер видеозаписи — 50 МБ.
* **Telegram**: максимальный размер видеозаписи или всех видеозаписей в посте — 50 МБ.
* **Facebook**\*: максимальный размер видеозаписи — 40 МБ.

{% hint style="warning" %}
\*Компания Meta Platforms Inc., владеющая социальными сетями Facebook и Instagram, признана экстремистской, и её деятельность запрещена на территории России.
{% endhint %}

{% hint style="warning" %}
Для выбора сразу нескольких видео с компьютера удерживайте клавишу Ctrl.&#x20;
{% endhint %}

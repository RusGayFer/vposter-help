# Форматирование текста

{% hint style="warning" %}
Форматирование текста в редакторе отложенного постинга доступно только для Telegram и Max.
{% endhint %}

### Как сделать форматирование?

Чтобы отформатировать текст, сначала выберите, куда его публиковать: в канал Телеграма или Макса. После выбора площадки в редакторе станет доступной возможность форматирования.

Теперь вы можете вставить или напечатать текст, затем выделить нужное слово или фразу. Над выделением появится меню с вариантами форматирования текста.

_Для каждого мессенджера меню с форматированием может различаться._

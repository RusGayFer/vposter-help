# Наборы страниц

## Что такое наборы страниц?

Наборы страниц позволяют собрать несколько сообществ в один набор. Например, вы можете создавать наборы из 20 сообществ и сразу этот набор выбирать при создании постов.

## Как создать набор страниц?

Для создании набора откройте раздел "Отложенные посты" и выберите подраздел "Наборы страниц". В этом разделе нажмите на кнопку "Создать набор. Укажите название набора и выберите сообщества для набора. После выбора сообществ нажмите на кнопку "Добавить".

{% hint style="warning" %}
Для выбора сразу нескольких сообществ с компьютера удерживайте клавишу Ctrl.&#x20;
{% endhint %}

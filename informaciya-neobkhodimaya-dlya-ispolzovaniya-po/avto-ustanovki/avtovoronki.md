# Автоворонки

## **Что такое автоворонка?**

**Автоматическая воронка продаж** - это серия касаний с пользователем, которые позволяют выстроить цепочку продаж от заинтересованного человека до покупателя вашего продукта/услуги. В отличие от классической воронки продаж, автоматическая воронка не требует контакта с лидом до этапа оформления сделки. Все действия, начиная с подписки на цепочку сообщений, и заканчивая отправкой заявки на покупку, совершаются в автоматическом режиме.

## Как подключить?

Чтобы подключить автоворонку в сообщество перейдите в раздел [Автоворонки](https://vposter.ru/autofunnels).

Чтобы добавить воронку нажмите на кнопку **Создать воронку**. Выберите из списка сообщество и добавьте название воронки.

Чтобы воронка была активна подключите Callback API (нажмите на ссылку **подключить Callback API**). Если у Вас несколько воронок, вы можете их передвигать местами для удобства. Для добавления этапов воронки нажмите на ссылку **Этапы**.

![Страница воронок](<../../.gitbook/assets/Безымянный (22).png>)

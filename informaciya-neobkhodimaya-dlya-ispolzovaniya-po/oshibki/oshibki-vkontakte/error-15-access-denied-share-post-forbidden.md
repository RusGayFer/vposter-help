# Error 15 Access denied: share post forbidden

При попытке отправить сообщение с вложением возникает ошибка:

{% hint style="danger" %}
{"error\_code": 15, "error\_msg": "Access denied: share post forbidden"}
{% endhint %}

## Решение проблемы <a href="#reshenie-problemy" id="reshenie-problemy"></a>

Для этого необходимо в Управлении сообществом ВКонтакте перейти в раздел Настройки и выключить опцию **Запретить делиться**.

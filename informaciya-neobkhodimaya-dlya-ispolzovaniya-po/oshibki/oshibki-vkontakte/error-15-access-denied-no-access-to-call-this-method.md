# Error 15 - Access denied: no access to call this method

При отправке запросов через API ВКонтакте может возвращаться следующая ошибка:

{% hint style="danger" %}
{"error\_code": 15, "error\_msg": "Access denied: no access to call this method"}
{% endhint %}

## Решение проблемы <a href="#reshenie-problemy" id="reshenie-problemy"></a>

1. Выйти из сервиса Впостер (нажать в правом верхнем углу на свой аватар, и в меню нажать на кнопку Выйти)
2. Заново авторизоваться через ВКонтакте
3. После авторизации ошибка пропадет.

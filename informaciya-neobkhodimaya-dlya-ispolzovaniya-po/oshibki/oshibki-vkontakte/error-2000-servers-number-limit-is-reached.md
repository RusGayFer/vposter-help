# Error 2000 - Servers number limit is reached

Что делать если при установке сервера в сообщество вы получите ошибку:

{% hint style="danger" %}
{"error":{"error\_code":2000,"error\_msg":"Servers number limit is reached"\}}
{% endhint %}

Данная ошибка означает, что у вас установлено 10 серверов (лимит) и больше вы не можете устанавливать новые. По правилам ВКонтакте, разрешается только 10 серверов для одного сообщества.

## Решение проблемы <a href="#reshenie-problemy" id="reshenie-problemy"></a>

Вам нужно перейти в **управление сообществом** в раздел **Работа с API**, далее вкладка **Callback API** и развернуть все сервера с полной версии [_vk.com_](https://vk.com/).

<figure><img src="https://sun1-87.userapi.com/impg/q-73yOpz3CwNdufr8sNjXEW0SSxR741x62ghRA/XFPfHauqXks.jpg?size=806x341&#x26;quality=96&#x26;sign=7fdba51b5b5c1d33376602801e993354&#x26;type=album" alt="Развертывание всех серверов сообщества"><figcaption><p>Развертывание всех серверов сообщества</p></figcaption></figure>

Здесь Вы увидите все Ваши добавленные сервера внешними сервисами. Если видите сервера с тем же названием, то смело **удаляйте которые Выше** (старые), а самый нижний по правилам активный (добавляются сверху вниз).

Так же если видите сервер с названием «**Сервер1**» или «**Сервер2**» тоже можете удалить, они являются пустыми.

<figure><img src="https://sun9-74.userapi.com/impg/K6w0Y352KaxjS8YpZ7BjLCJjdu9TWRPT6c9FFQ/VSrTsypKx1Y.jpg?size=563x239&#x26;quality=96&#x26;sign=7399e0118fa59331ad48c17585e32edc&#x26;type=album" alt="Удаление сервера при выборе"><figcaption><p>Удаление сервера при выборе</p></figcaption></figure>

Такими способами вы можете сами освободить место даже без всяких знаний о серверах.

Имейте ввиду, если без знания вы просто удаляете все сервера, то может перестать работать любой сервис с вашим сообществом либо какое-то подключенное приложение.

# Error 15 - Access denied: group messages are disabled

Когда в сообществе ВКонтакте выключены сообщения, показывается следующее уведомление об ошибке:

{% hint style="danger" %}
{"error\_code": 15, "error\_msg": "Access denied: group messages are disabled"}
{% endhint %}

#### Решение проблемы <a href="#reshenie-problemy" id="reshenie-problemy"></a>

Для исправления данной ошибки необходимо пройти в Управлении сообществом ВКонтакте в раздел Сообщения и включить их.

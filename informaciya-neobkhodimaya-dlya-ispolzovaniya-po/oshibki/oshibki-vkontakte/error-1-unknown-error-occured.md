# Error 1 - Unknown error occured

При загрузке изображений может возникать следующая ошибка:

{% hint style="danger" %}
{"error\_code": 1, "error\_msg": "Unknown error occured"}
{% endhint %}

Похоже, вы достигли количественного лимита на загрузку изображений. Необходимо подождать и продолжить загрузку на следующий день.

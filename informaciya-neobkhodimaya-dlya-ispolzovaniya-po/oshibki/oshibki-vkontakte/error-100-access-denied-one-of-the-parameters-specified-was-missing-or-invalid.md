# Error 100 - Access denied: One of the parameters specified was missing or invalid

При отправке запросов через API ВКонтакте может возвращаться следующая ошибка:

{% hint style="danger" %}
{"error\_code": 100, "error\_msg": "One of the parameters specified was missing or invalid: ..."}
{% endhint %}

## Решение проблемы <a href="#reshenie-problemy" id="reshenie-problemy"></a>

Ошибка указывает на то, что прикреплено удаленное или не верное вложение.

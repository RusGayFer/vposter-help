# Информация об access\_token

## Почему слетает access\_token?

**access\_token** позволяет сервису публиковать посты от вашего имени, получать данные из ВКонтакте и другие действия. При потере токена, многие действия прекращаются.

_**Возможные причины потери токена:**_

1. Заморозка аккаунта на время;
2. Смена пароля;
3. Автоматический сброс токена системой VK при массовой активности аккаунта;
4. Прочие действия

{% hint style="warning" %}
В нашем сервисе токен обновляется на новый автоматически при авторизации через VK ID. При каждом входе мы обновляем ваш токен.
{% endhint %}

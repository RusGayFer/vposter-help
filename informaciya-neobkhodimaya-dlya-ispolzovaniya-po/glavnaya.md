# Главная

Данная страница содержит слайдер с последними новостями сервиса и виджеты:

* Рост числа подписчиков за сегодня
* Статистика ваших сообществ

## О виджете "Рост числа подписчиков за сегодня"

Данный виджет позволяет отслеживать динамику роста числа подписчиков в ваших сообществах ВКонтакте.

## О виджете "Статистика ваших сообществ"

Данный виджет позволяет отслеживать количество сообществ с разными правами в группах ВКонтакте.

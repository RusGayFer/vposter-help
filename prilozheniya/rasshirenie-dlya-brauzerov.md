# Расширение для браузеров

Расширение для браузера "Впостер Tools — Инструмент для SMM" значительно расширяет возможности сервиса.

Расширение позволяет:

* Копировать посты по специальной кнопке под постами ВКонтакте.
* Копировать изображения из ВКонтакте при клике правой кнопкой мыши.

В настоящее время есть версии для браузеров: Chrome, Opera, Yandex, и Microsoft Edge (браузеры на движке Chromium) и Firefox.

### Где скачать расширение?

1. [Установить для Chrome](https://chrome.google.com/webstore/detail/kfmbhmbcegjfkhccecfkfcknkehbfmoh)
2. [Установить для Firefox](https://addons.mozilla.org/ru/firefox/addon/vposter-tools/)
